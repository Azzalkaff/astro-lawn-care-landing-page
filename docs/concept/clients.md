# Content Generation Rules

* Use Australian English.
* Write naturally and professionally.
* Avoid keyword stuffing.
* Focus on clarity over marketing language.
* Every page should include a clear call-to-action.
* Service descriptions should explain benefits and expected outcomes.
* Reviews should sound authentic and vary in writing style.
* Gallery descriptions should reference realistic suburbs and completed work.
* Keep paragraphs short and easy to scan.
